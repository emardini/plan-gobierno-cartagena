# Aportes

Aquí quedan registrados los aportes de quienes colaboran, una vez que el cuidador los recibe. Cada uno se guarda con una ficha corta (ver `colaboracion/plantillas.md`) y un estado: **recibido**, **revisado**, **verificado**, **incorporado** o **descartado con razón**.

Nombre sugerido para cada archivo: `AAAA-MM-DD_codigo-de-tarea_tema.md`.

Todo lo que contenga datos personales de terceros (conversaciones, contactos, listas) se guarda en `aportes/privado/`, que no se versiona.

Cuando un aporte se incorpora al plan, se agrega una línea al final de esta lista con el archivo, la sección donde entró y, si la persona lo permitió, su nombre en los agradecimientos.
