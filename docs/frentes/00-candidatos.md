# Candidatos a frente y cómo se eligen

El plan nacional tiene quince frentes porque un país los necesita. Una alcaldía no debe copiarlos: debe escoger los pocos, de seis a diez, que la evidencia del diagnóstico justifique, y descartar con explicación lo demás. Cada frente que se elija se escribe en su propio documento con el mismo esqueleto: diagnóstico con datos, lo que ya está construido y se conserva, la propuesta, la clasificación de competencia, el costo con fuente, el indicador con medición independiente, el riesgo principal y el límite honesto.

## Criterios de selección

Se entra a la lista de frentes cuando se cumplen tres cosas: el diagnóstico muestra que el problema pesa, el Distrito tiene una palanca real (verbo EJECUTA, o GESTIONA con plazo creíble) y hay una forma de medir el resultado con un tercero. Lo que falle en alguna se explica y se deja fuera, o pasa al plan como gestión ante otro nivel.
